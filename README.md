# Source Club Brasil Advanced — Atualizações

Canal oficial de downloads das atualizações do SCB Advanced para Windows.

## Atualizar o jogo

Abra `SourceAdvancedLauncher.exe` na pasta da sua instalação e clique em **ATUALIZAR GAME**. O launcher baixa o pacote cumulativo, verifica a assinatura e os arquivos e instala a versão disponível, preservando as configurações pessoais.

As atualizações ficam em [Releases](https://github.com/CoresPST/scb-updates/releases/latest). Os downloads são públicos e não exigem conta do GitHub. Os pacotes exigem a instalação base do jogo; não são instaladores completos.

Canal utilizado pelo launcher:

```
https://github.com/CoresPST/scb-updates/releases/latest/download/manifest.json
```

O manifesto assinado aponta para o pacote da versão exata. O launcher verifica a assinatura, o tamanho e os hashes antes de aplicar a atualização.

Este repositório distribui apenas os arquivos públicos das atualizações. As chaves de assinatura permanecem no ambiente do publicador.
